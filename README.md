# E-Commerce-Sales-Analysis-SQL-Python
End-to-end e-commerce data analysis using SQL and Python, covering customer, order, product, seller, revenue, retention, and sales trend analysis.

##  Project Deliverables

### SQL Analysis
15 analytical SQL problems covering:
- Basic Analysis
- Intermediate Analysis
- Advanced Analysis
- CTEs
- Aggregations
- Window Functions
- Ranking
- Customer & Sales Analysis

###  Python Analysis
Google Colab notebook covering:
- Data Preparation
- Pandas Analysis
- Business Metrics
- Exploratory Analysis
- Matplotlib Visualizations

### Portfolio Presentation

The project presentation provides a structured overview of the complete e-commerce analysis performed using SQL and Python.

It covers the project objective, dataset structure, analytical workflow, basic and intermediate analysis, advanced customer and sales analysis, visual findings, and key business results.

The presentation brings together the major insights from the SQL analysis and Python visualizations into a concise portfolio-ready format.

The updated PDF presentation includes SQL queries, corresponding Python analysis, output screenshots, and visualizations in a structured, professional portfolio format. It summarizes the analytical workflow and results across all 15 problems, making the project easier to review and understand.
